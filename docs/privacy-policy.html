Privacy Policy - Cookie Profile Switcher Plus

Last updated: February 10, 2026

English

Cookie Profile Switcher Plus stores profile and cookie-session data locally in the user's browser using Chrome extension storage APIs.

Data Collection

  • We do not collect personal data on external servers.
  • We do not sell or share user data with third parties.
  • We do not run analytics or tracking services in this extension.

Data Storage

  • Data is stored locally in chrome.storage.local.
  • Profile data may include cookie values required for session switching on domains selected by the user.

Data Transmission

  • The extension does not transmit profile or cookie data to external services.
  • Network requests only occur when the user navigates websites normally in the browser.

Permissions

  • cookies: read/write cookies for selected domains to switch sessions.
  • tabs: detect active tab and reload after profile switch.
  • storage: store profile data locally.
  • Host permissions (http://*/*, https://*/*) are required to manage cookies across user-selected sites.

User Control

  • Users can create, edit, export, import, and delete profile data.
  • Users can remove the extension at any time, which removes extension data according to browser behavior.

Contact

For questions about this policy, contact: emerysteele@gmail.com

Portugues (PT-BR)

O Cookie Profile Switcher Plus armazena dados de perfis e sessoes de cookies localmente no navegador do usuario usando as APIs de armazenamento de extensoes do Chrome.

Coleta de Dados

  • Nao coletamos dados pessoais em servidores externos.
  • Nao vendemos nem compartilhamos dados de usuarios com terceiros.
  • Nao utilizamos analytics ou servicos de rastreamento nesta extensao.

Armazenamento de Dados

  • Os dados sao armazenados localmente em chrome.storage.local.
  • Os dados de perfil podem incluir valores de cookies necessarios para troca de sessao nos dominios selecionados pelo usuario.

Transmissao de Dados

  • A extensao nao transmite dados de perfil ou cookies para servicos externos.
  • Requisicoes de rede ocorrem apenas quando o usuario navega normalmente em sites no navegador.

Permissoes

  • cookies: ler/gravar cookies de dominios selecionados para alternar sessoes.
  • tabs: identificar a aba ativa e recarregar apos troca de perfil.
  • storage: armazenar dados de perfil localmente.
  • Permissoes de host (http://*/*, https://*/*) sao necessarias para gerenciar cookies em sites selecionados pelo usuario.

Controle do Usuario

  • O usuario pode criar, editar, exportar, importar e excluir dados de perfil.
  • O usuario pode remover a extensao a qualquer momento, o que remove os dados da extensao conforme o comportamento do navegador.

Contato

Para duvidas sobre esta politica, contato: emerysteele@gmail.com

This policy applies to Cookie Profile Switcher Plus for Chrome and Edge.
